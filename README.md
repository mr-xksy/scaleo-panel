# Scaleo-панель

Telegram Mini App для Scaleo-бота (приватный репозиторий `scaleo-bot`).

- Только вёрстка: в коде нет ключей, токенов, адресов трекера и данных.
- Списки рекламодателей, партнёров и офферов бот передаёт при открытии в части адреса после `#`.
- Панель только собирает поля формы и отправляет их боту через `Telegram.WebApp.sendData`. Бот проверяет всё заново и создаёт запись после подтверждения.

Адрес: https://mr-xksy.github.io/scaleo-panel/

Любой push в `main` автоматически обновляет страницу через GitHub Pages.
